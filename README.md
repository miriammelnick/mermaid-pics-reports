# mermaid.pics photo reports

Corrections for [mermaid.pics](https://mermaid.pics): a wrong species ID,
date, dive site, or anything else that looks off on a photo page.

To report a photo, open it on the site and click **Something look wrong?
Report it** at the bottom of the page. The issue form opens with the photo
already filled in, so all you need to add is what's wrong. You'll need a
GitHub account.
